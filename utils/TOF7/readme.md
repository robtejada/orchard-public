This package contains source code for read-in and usage of five asci-format
tables. The tables contain the Theory-of-Figures [1] coefficients to the 7th order, 
as described in Ref [2].

The five tables can be found in the 'TABLES' folder.

Source code in MATLAB and Python for read-in of the tables can be found in the
'MATL_PY_NM' folder. For using the tables, copy them into the 'MATL_PY_NM' folder.
See the respective readme.md file therein.

Source code in C++ for read-in and of the tables and basic usage can be found
in the 'CPP_NN' folder. See the instructions in the respective 'toff_readme.txt' 
file therein.


Ref [1]: Zharkov V.N. and Trubitsyn V.P. (1978),  'Physics of Planetary Interiors',
         Tucson, AZ: Parchart.
Ref [2]: Nettelmann N., Movshovitz M., Ni D., et al, Planetary Science J. (under review)
